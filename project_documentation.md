# Zomato Dataset Cleaning & Preprocessing

This repository contains a Jupyter Notebook dedicated to cleaning, preprocessing, and preparing the Zomato restaurant dataset for downstream exploratory data analysis (EDA) or machine learning tasks.

## Overview

Raw datasets often contain irrelevant features, duplicate records, formatting inconsistencies, and missing values. This project demonstrates a step-by-step data cleaning pipeline using Python and `pandas` to transform the raw `zomato.csv` file into a structured, analysis-ready dataset (`zomoto_clean_dataset`).

## Data Cleaning Pipeline

The notebook performs the following operations:
1. **Data Ingestion:** Loads the raw `zomato.csv` dataset into a pandas DataFrame.
2. **Feature Selection:** Drops non-essential or high-cardinality text columns (`url`, `address`, `name`, `listed_in(city)`, `rest_type`, `dish_liked`, `reviews_list`, `menu_item`, `phone`) to streamline the dataset.
3. **Deduplication:** Removes duplicate rows to ensure data integrity.
4. **Handling Missing Values:**
   - Drops records where `location` is missing.
   - Imputes missing `cuisines` values with `'unknown'`.
5. **Data Type Formatting & Imputation:**
   - Cleans string formatting (removing commas) in the `approx_cost(for two people)` column and converts it to integers.
   - Replaces missing/zero cost values with the column mean.
6. **Data Export:** Saves the cleaned DataFrame to a new CSV file (`zomoto_clean_dataset`).

## Getting Started

### Prerequisites

Ensure you have Python 3.8 or higher installed on your system.

### Installation

1. Clone this repository to your local machine:
   ```bash
   git clone <your-repository-url>
   cd <your-repository-folder>
   ```

2. Install the required Python packages:
   ```bash
   pip install -r requirements.txt
   ```

### Usage

1. Place the raw `zomato.csv` file in the root directory of the project.
2. Launch Jupyter Notebook or JupyterLab:
   ```bash
   jupyter notebook
   ```
3. Open the notebook and run the cells sequentially. *(Note: Ensure the string quote typo on line 2 `pd.read_csv('zomato.csv')` is corrected before running all cells).*
